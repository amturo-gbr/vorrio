Docker Compose starten, ersten Owner anlegen und Vorrio im Browser oder als PWA verwenden.

Installation öffnen Dokumentation 
$ git clone https://github.com/amturo-gbr/vorrio.git
$ cd vorrio
$ cp .env.example .env
$ docker compose up -d --build
