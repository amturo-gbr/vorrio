# Vorrio-API-Referenz

Die öffentliche REST-API ist unter `/api/v1` versioniert. Diese Referenz wird aus dem eingecheckten OpenAPI-Vertrag erstellt und erfordert keine laufende Vorrio-Instanz.

Verwenden Sie bei Anfragen den eigenen HTTPS-Ursprung einer echten Installation. Unterstützte Automatisierungsendpunkte akzeptieren bereichsbezogene Bearer-Tokens, die von einem Eigentümer oder Administrator erstellt wurden. Platzieren Sie niemals ein Token in einer URL, einem öffentlichen Repository oder einer im Browser sichtbaren Dashboard-Konfiguration.
