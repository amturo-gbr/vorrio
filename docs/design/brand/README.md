# Vorrio brand mark

The selected Vorrio mark combines three organized inventory modules with a
negative-space `V`. It replaces the earlier receipt-sheet symbol throughout the
PWA and public documentation.

## Production assets

- `frontend/public/brand/vorrio-mark.png`: transparent green mark for light
  surfaces;
- `frontend/public/brand/vorrio-mark-white.png`: transparent white mark for dark
  surfaces;
- `frontend/public/pwa-icon.png`: maskable 1024 px app icon with safe padding;
- `vorrio-logo-final.png`: approved presentation board for the selected mark;
- `vorrio-mark-chroma-source.png`: construction source retained for future
  re-extraction, not for product use.

## Usage

- Primary green: `#176B35`.
- Dark green: `#10592B`.
- Keep clear space around the symbol equal to at least half the gap between its
  two upper modules.
- Do not rotate the mark, add effects, recolor individual modules or place text
  inside it.
- Use the white version on green or dark surfaces and the green version on
  white or light surfaces.
