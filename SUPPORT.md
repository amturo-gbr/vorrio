# Support

Use GitHub issues for reproducible bugs and focused feature requests. Use
GitHub Discussions for installation and workflow questions after Discussions
are enabled for the public repository.

Before asking for help:

1. read [Installation](docs/en/INSTALLATION.md),
   [Configuration](docs/en/CONFIGURATION.md) and
   [Backup and restore](docs/en/BACKUP-RESTORE.md);
2. record the exact Vorrio version or immutable image digest;
3. check `/api/health` and `/api/readiness`;
4. reproduce with synthetic data where possible;
5. remove API keys, cookies, receipt text, addresses, local hostnames, database
   files and personal paths from every screenshot or log.

Security vulnerabilities must use a private GitHub security advisory. Do not
open a public issue for a vulnerability.

Support is best effort before the stable 1.0 policy. Amturo UG prioritizes
security, data integrity and regressions affecting supported self-hosted
installations.
